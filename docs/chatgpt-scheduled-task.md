# ChatGPT 已安排任务：Smart Home GitHub 24h 自动同步

> 起草于 2026-08-12，用于将本对话的 GitHub 同步工作固化为每 24 小时运行的已安排任务。

## 一、任务信息

| 项目     | 内容                                                                |
| -------- | ------------------------------------------------------------------- |
| 任务名称 | Smart Home GitHub 24h 自动同步                                      |
| 运行周期 | 每 24 小时一次（默认每天 03:00，北京时间，可在 Scheduled 页面调整） |
| 运行环境 | ChatGPT 桌面应用，项目`E:\smart_home`（本地项目模式）             |
| 结果去向 | 回到当前对话（本对话即 GitHub 同步对话）                            |

## 二、可直接粘贴的任务指令

把下面整段内容作为任务的运行指令（建议同时保留本文件作为版本记录）：

```text
你是 Smart Home 项目的 GitHub 自动同步任务，每 24 小时运行一次，每次运行结束后回到当前对话。

执行步骤：
1. 进入项目目录 E:\smart_home，运行 git status 检查未提交改动。
2. 若有本地改动：先检查并排除敏感信息，然后以中文提交信息提交到 main。
3. 运行 E:\smart_home\scripts\sync-github.ps1：该脚本会重建清理后的发布副本、扫描敏感信息、拉取并推送到 git@github.com:icenewtown/unified-smart-home.git。
4. 查看 %LOCALAPPDATA%\SmartHomePublish\sync.log 与脚本退出码：
   - 成功：用 1-2 句话总结本次推送内容（或说明无改动）。
   - 失败或 ABORT：粘贴关键错误并给出原因判断，不要盲目重试。
5. 顺带检查仓库细节（README、CHANGELOG、徽章、topics）是否有值得改进之处；有明显改进再动手，不要为了改而改。

硬性约束：
- 绝不提交、打印或公开任何敏感信息：服务器 IP、账号邮箱、设备 ID、GitHub 令牌等。
- 令牌只从 %LOCALAPPDATA%\SmartHomePublish\gh-token.txt 读取，绝不写入仓库或对话日志。
- 若连续两次运行失败，暂停并请我处理。
```

## 三、创建方式（二选一）

### 方式 A：在本对话中直接安排（推荐）

在输入框发送下面这句话，并按应用弹出的调度面板确认：

```text
请把这个对话安排为已安排任务：每 24 小时运行一次，运行后回到当前对话。运行指令如下：

【粘贴上面“二、可直接粘贴的任务指令”整段内容】
```

### 方式 B：从 Scheduled 页面新建

1. ChatGPT 桌面应用左上角菜单选择 **ChatGPT**，在侧边栏打开 **已安排任务（Scheduled）**。
2. 点击新建任务，粘贴“二、可直接粘贴的任务指令”整段内容。
3. 频率选择 **每天**（或自定义 24 小时间隔），时间默认 03:00。
4. 项目选择 `E:\smart_home`，运行位置选择 **本地项目**（如需隔离改动可选 worktree）。
5. 保存后可在 Scheduled 页面查看、暂停、编辑或删除。

## 四、注意事项

- 本地项目任务需要电脑保持开机、ChatGPT 桌面应用保持运行，否则不会执行。
- 已安排任务无人值守运行，无法弹窗请求批准：需要提前在权限/规则中允许 git 联网与访问 `%LOCALAPPDATA%\SmartHomePublish`，否则拉取/推送会失败。
- 与 Windows 计划任务 `SmartHomeGitHubSync`（每天 03:00）功能重复：建议启用 ChatGPT 任务后，在“任务计划程序”中暂停或删除旧任务，或把两者时间错开，避免重复推送。
- 删除本对话会自动暂停关联任务；任务可在 Scheduled 页面暂停、恢复或删除。
- 令牌文件不入库；若轮换令牌，请更新 `%LOCALAPPDATA%\SmartHomePublish\gh-token.txt`。
