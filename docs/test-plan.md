# 测试与验收清单

## 设备接入

- [ ] 小米：至少一台设备在 HA 中实体状态与实际一致，开关/模式/温度控制生效。
- [ ] 美的：至少一台设备在 HA 中实体状态与实际一致，开关/模式控制生效。
- [ ] 格力：至少一台设备在 HA 中实体状态与实际一致，开关/模式/温度控制生效。
- [ ] 三品牌原 App 仍可正常控制（备用通道）。

## 客户端

- [ ] 手机 HA App 在家用网络登录并控制成功。
- [ ] 手机 HA App 在移动网络（外网）登录并控制成功。
- [ ] 网页端登录成功。

## 语音

- [ ] "小爱同学，打开客厅空调"等指令对三家设备各测试至少一句。
- [ ] 语音控制后 HA 状态立即刷新。

## 自动化

- [ ] "一键全关空调"手动触发后三家空调全部关闭。
- [ ] 离家模式按预期触发。
- [ ] 定时任务按预期时间执行。

## 故障恢复

- [ ] `docker restart homeassistant` 后三个集成自动重连。
- [ ] 美居账号被踢后重新登录成功。
- [ ] 用 HA 备份 `.tar` 在临时容器完成一次恢复演练。
- [ ] 服务器重启后容器自动拉起。

## 安全

- [ ] 管理员账号已开启 2FA。
- [ ] 安全组仅放行所需端口。
- [ ] 确认 `config/`、`secrets.yaml` 等敏感内容未提交 git。
